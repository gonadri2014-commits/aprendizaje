# aprendizaje

## Playwright + lenguaje natural (MCP)

- **Playwright MCP** (`.mcp.json`): Claude controla el navegador con instrucciones en español,
  ej. *"Abre el portal del banco, descarga el extracto y resume el saldo"*.
- **Playwright Test**: `npm test` corre los tests de `tests/`.

### Instalación local
```bash
npm install
npx playwright install chromium   # solo fuera de la nube
```
